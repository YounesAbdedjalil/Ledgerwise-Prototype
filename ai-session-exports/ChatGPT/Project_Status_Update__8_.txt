1. Import attribution can be overwritten
This backfill currently does:

If imported_by already contains valid importer attribution, this overwrites it.
The safer version is:
set imported_by = coalesce(imported_by, verified_by)

That preserves existing attribution and uses the old verified_by value only when no importer is recorded.
2. Table privileges need explicit hardening
The migration replaces RLS policies, but it does not explicitly revoke broad table privileges from anon or narrow direct mutation privileges for authenticated.
RLS and SQL grants are separate protections:

RLS determines which rows a role can access.
Grants determine which database operations that role is permitted to attempt.

Our transactional booking design should revoke direct booking mutations and route them through narrowly scoped database functions. We should also revoke anonymous access to the relevant application tables without breaking legitimate authenticated workflows.

async function loadSlot(
  supabase: ServerSupabase,
  slotId: string
): Promise<{ slot?: SlotRow; error?: string }> {
  const { data, error } = await supabase
    .from("calendar_slots")
    .select("id,start_time,end_time,timezone,source,is_available")
    .eq("id", slotId)
    .maybeSingle();
  if (error) return { error: error.message };
  if (!data) return { error: "Slot not found." };
  return { slot: data as SlotRow };
}

async function recordGoogleSync(
  supabase: ServerSupabase,
  bookingId: string,
  result: { status: "not_configured" | "synced" | "failed"; eventId?: string },
  deleted = false
): Promise {
  if (result.status === "not_configured") return;
  if (result.status === "synced") {
    await supabase
      .from("bookings")
      .update(
        deleted
          ? {
              google_event_id: null,
              calendar_sync_status: "deleted",
              calendar_synced_at: new Date().toISOString(),
            }
          : {
              ...(result.eventId ? { google_event_id: result.eventId } : {}),
              calendar_sync_status: "synced",
              calendar_synced_at: new Date().toISOString(),
            }
      )
      .eq("id", bookingId);
    return;
  }
  await supabase
    .from("bookings")
    .update({ calendar_sync_status: "failed" })
    .eq("id", bookingId);
}
async function checkSuppressed(
  supabase: ServerSupabase,
  email: string
): Promise<{ ok: boolean; error?: string }> {
  try {
    if (await isSuppressed(supabase, email)) {
      return {
        ok: false,
        error: "This contact is on the permanent suppression list. A booking cannot be created or confirmed.",
      };
    }
    return { ok: true };
  } catch (error) {
    return {
      ok: false,
      error:
        error instanceof Error
          ? error.message
          : "The suppression check failed. Apply the database migrations first.",
    };
  }
}
async function checkSlotFree(
  supabase: ServerSupabase,
  slot: SlotRow,
  ignoreBookingId?: string
): Promise<{ ok: boolean; error?: string }> {
  const { data: overlappingSlots, error: slotError } = await supabase
    .from("calendar_slots")
    .select("id")
    .lt("start_time", slot.end_time)
    .gt("end_time", slot.start_time);
  if (slotError) return { ok: false, error: slotError.message };
  const slotIds = Array.from(
    new Set([slot.id, ...(overlappingSlots ?? []).map((row) => row.id)])
  );
  const { data, error } = await supabase
    .from("bookings")
    .select("id")
    .in("slot_id", slotIds)
    .in("status", [...OCCUPYING_BOOKING_STATUSES]);
  if (error) return { ok: false, error: error.message };
  const conflict = (data ?? []).find((row) => row.id !== ignoreBookingId);
  if (conflict) {
    return { ok: false, error: "That time is already held by another booking." };
  }
  return { ok: true };
}
export async function createSlot(input: {
  startTime: string;
  endTime: string;
  timezone: string;
}): Promise {
  const supabase = await createClient();
  const user = await getSessionUser(supabase);
  if (!user) return { ok: false, error: "Not signed in." };
  const validation = validateSlotInput(input);
  if (!validation.ok) return { ok: false, error: validation.errors.join(" ") };
  const { data, error } = await supabase
    .from("calendar_slots")
    .insert({
      start_time: input.startTime,
      end_time: input.endTime,
      timezone: input.timezone,
      source: "internal",
      external_id: null,
      is_available: true,
      fetched_at: new Date().toISOString(),
    })
    .select("id")
    .single();
  if (error || !data) {
    return {
      ok: false,
      error:
        error?.message ??
        "The slot could not be created. Apply migration 02 if the source check rejects 'internal'.",
    };
  }
  await writeAudit(supabase, {
    actorId: user.id,
    action: "calendar_slot_created",
    entityType: "calendar_slots",
    entityId: data.id,
    detail: {
      start_time: input.startTime,
      end_time: input.endTime,
      timezone: input.timezone,
      source: "internal",
    },
  });
  revalidateCalendar();
  return { ok: true, slotId: data.id, message: "Internal slot created." };
}
export async function deleteSlot(slotId: string): Promise {
  const supabase = await createClient();
  const user = await getSessionUser(supabase);
  if (!user) return { ok: false, error: "Not signed in." };
  if (!isUuid(slotId)) return { ok: false, error: "Invalid slot ID." };
  const loaded = await loadSlot(supabase, slotId);
  if (!loaded.slot) return { ok: false, error: loaded.error };
  const { data: active, error } = await supabase
    .from("bookings")
    .select("id")
    .eq("slot_id", slotId)
    .in("status", [...OCCUPYING_BOOKING_STATUSES])
    .limit(1);
  if (error) return { ok: false, error: error.message };
  if ((active ?? []).length > 0) {
    return {
      ok: false,
      error: "Cancel or reschedule the active booking before deleting this slot.",
    };
  }
  const { error: deleteError } = await supabase
    .from("calendar_slots")
    .delete()
    .eq("id", slotId);
  if (deleteError) return { ok: false, error: deleteError.message };
  await writeAudit(supabase, {
    actorId: user.id,
    action: "calendar_slot_deleted",
    entityType: "calendar_slots",
    entityId: slotId,
    detail: {
      start_time: loaded.slot.start_time,
      end_time: loaded.slot.end_time,
    },
  });
  revalidateCalendar();
  return { ok: true, slotId, message: "Slot deleted." };
}
export async function bookSlot(input: {
  slotId: string;
  companyId?: string | null;
  conversationId?: string | null;
  prospectName: string;
  prospectEmail: string;
  timezone: string;
}): Promise {
  const supabase = await createClient();
  const user = await getSessionUser(supabase);
  if (!user) return { ok: false, error: "Not signed in." };
  if (!isUuid(input.slotId)) return { ok: false, error: "Invalid slot ID." };
  let companyId = input.companyId && isUuid(input.companyId) ? input.companyId : null;
  const conversationId =
    input.conversationId && isUuid(input.conversationId) ? input.conversationId : null;
  let prospectName = input.prospectName;
  let prospectEmail = normalizeEmail(input.prospectEmail);
  if (conversationId) {
    const { data: conversation } = await supabase
      .from("conversations")
      .select("id,company_id,contact_email,status")
      .eq("id", conversationId)
      .maybeSingle();
    if (!conversation) return { ok: false, error: "Conversation not found." };
    if (conversation.status === "suppressed") {
      return {
        ok: false,
        error: "This contact is suppressed. A booking cannot be created.",
      };
    }
    companyId = companyId ?? conversation.company_id;
    if (!prospectEmail) prospectEmail = normalizeEmail(conversation.contact_email);
  }
  if (companyId) {
    const { data: company } = await supabase
      .from("companies")
      .select("name,contact_name,contact_email")
      .eq("id", companyId)
      .maybeSingle();
    if (company) {
      if (!prospectName.trim() && company.contact_name !== "unknown") {
        prospectName = company.contact_name;
      }
      if (!prospectEmail && company.contact_email) {
        prospectEmail = normalizeEmail(company.contact_email);
      }
    }
  }
  if (!isValidEmail(prospectEmail)) {
    return { ok: false, error: "A valid prospect email is required." };
  }
  const suppression = await checkSuppressed(supabase, prospectEmail);
  if (!suppression.ok) return { ok: false, error: suppression.error };
  const cleanProspectName = trimText(prospectName, 200);
  if (!cleanProspectName) {
    return { ok: false, error: "A prospect name is required." };
  }
  const validation = validateBookingInput({
    prospectName: cleanProspectName,
    prospectEmail,
    timezone: input.timezone,
  });
  if (!validation.ok) return { ok: false, error: validation.errors.join(" ") };
  const loaded = await loadSlot(supabase, input.slotId);
  if (!loaded.slot) return { ok: false, error: loaded.error };
  const { slot } = loaded;
  if (!slot.is_available) {
    return { ok: false, error: "That slot is marked unavailable." };
  }
  if (Date.parse(slot.end_time) <= Date.now()) {
    return { ok: false, error: "That slot is in the past." };
  }
  const free = await checkSlotFree(supabase, slot);
  if (!free.ok) return { ok: false, error: free.error };
  const { data: inserted, error } = await supabase
    .from("bookings")
    .insert({
      company_id: companyId,
      conversation_id: conversationId,
      slot_id: input.slotId,
      prospect_name: cleanProspectName,
      prospect_email: prospectEmail,
      timezone: input.timezone,
      status: "pending",
    })
    .select("id")
    .single();
  if (error || !inserted) {
    if (error?.code === "23505") {
      return { ok: false, error: "That slot was just taken. Refresh and choose another." };
    }
    return { ok: false, error: error?.message ?? "The booking could not be created." };
  }
  if (conversationId) {
    await supabase
      .from("conversations")
      .update({ status: "human_takeover", booking_request: false })
      .eq("id", conversationId);
  }
  await writeAudit(supabase, {
    actorId: user.id,
    action: "booking_created",
    entityType: "bookings",
    entityId: inserted.id,
    detail: {
      slot_id: input.slotId,
      company_id: companyId,
      conversation_id: conversationId,
      prospect_email: prospectEmail,
      status: "pending",
    },
  });
  const google = await syncBookingToGoogle({
    summary: Ledgerwise call: ${cleanProspectName},
    description: [
      Prospect: ${cleanProspectName},
      Email: ${prospectEmail},
      Company: ${companyId ?? "unknown"},
      "Created from the Ledgerwise prototype.",
    ].join("\n"),
    startTime: slot.start_time,
    endTime: slot.end_time,
    timezone: slot.timezone,
  });
  await recordGoogleSync(supabase, inserted.id, google);
  revalidateCalendar();
  revalidatePath(/conversations/${conversationId ?? ""});
  return {
    ok: true,
    bookingId: inserted.id,
    slotId: input.slotId,
    message:
      google.status === "synced"
        ? "Booking created and synced to Google Calendar."
        : google.status === "failed"
          ? "Booking created on the internal calendar. Google Calendar sync failed."
          : "Booking created on the internal calendar.",
  };
}
export async function confirmBooking(
  bookingId: string
): Promise {
  const supabase = await createClient();
  const user = await getSessionUser(supabase);
  if (!user) return { ok: false, error: "Not signed in." };
  if (!isUuid(bookingId)) return { ok: false, error: "Invalid booking ID." };
  const loaded = await loadBooking(supabase, bookingId);
  if (!loaded.booking) return { ok: false, error: loaded.error };
  const { booking } = loaded;
  if (booking.status !== "pending" && booking.status !== "needs_human") {
    return { ok: false, error: "Only a pending or needs-human booking can be confirmed." };
  }
  const suppression = await checkSuppressed(supabase, booking.prospect_email);
  if (!suppression.ok) {
    return {
      ok: false,
      error: ${suppression.error} Cancel the booking instead.,
    };
  }
  const { data: updated, error } = await supabase
    .from("bookings")
    .update({ status: "confirmed" })
    .eq("id", bookingId)
    .eq("status", booking.status)
    .select("id")
    .maybeSingle();
  if (error) return { ok: false, error: error.message };
  if (!updated) {
    return {
      ok: false,
      error: "The booking changed while you were confirming it. Refresh and try again.",
    };
  }
  let syncNote = "";
  let syncStatus = "not_attempted";
  if (!booking.google_event_id && booking.slot_id) {
    const loadedSlot = await loadSlot(supabase, booking.slot_id);
    if (loadedSlot.slot) {
      const google = await syncBookingToGoogle(
        bookingEventInput(booking, loadedSlot.slot, loadedSlot.slot.timezone)
      );
      syncStatus = google.status;
      await recordGoogleSync(supabase, bookingId, google);
      syncNote =
        google.status === "synced"
          ? " Google Calendar event created."
          : google.status === "failed"
            ? " Google Calendar sync failed; the internal booking is still confirmed."
            : "";
    }
  }
  await writeAudit(supabase, {
    actorId: user.id,
    action: "booking_confirmed",
    entityType: "bookings",
    entityId: bookingId,
    detail: {
      previous_status: booking.status,
      slot_id: booking.slot_id,
      google_sync_status: booking.google_event_id ? "already_linked" : syncStatus,
    },
  });
  revalidateCalendar();
  return { ok: true, bookingId, message: Booking confirmed.${syncNote} };
}
export async function cancelBooking(
  bookingId: string,
  reason: string
): Promise {
  const supabase = await createClient();
  const user = await getSessionUser(supabase);
  if (!user) return { ok: false, error: "Not signed in." };
  if (!isUuid(bookingId)) return { ok: false, error: "Invalid booking ID." };
  const cleanReason = trimText(reason, 500);
  if (!cleanReason) return { ok: false, error: "A cancellation reason is required." };
  const loaded = await loadBooking(supabase, bookingId);
  if (!loaded.booking) return { ok: false, error: loaded.error };
  const { booking } = loaded;
  if (
    booking.status !== "pending" &&
    booking.status !== "confirmed" &&
    booking.status !== "needs_human"
  ) {
    return { ok: false, error: "This booking is already cancelled or rescheduled." };
  }
  const { data: updated, error } = await supabase
    .from("bookings")
    .update({ status: "cancelled" })
    .eq("id", bookingId)
    .eq("status", booking.status)
    .select("id")
    .maybeSingle();
  if (error) return { ok: false, error: error.message };
  if (!updated) {
    return {
      ok: false,
      error: "The booking changed while you were cancelling it. Refresh and try again.",
    };
  }
  let syncNote = "";
  if (booking.google_event_id) {
    const google = await deleteGoogleEvent(booking.google_event_id);
    if (google.status === "not_configured") {
      await supabase
        .from("bookings")
        .update({ calendar_sync_status: "failed" })
        .eq("id", bookingId);
      syncNote =
        " The internal booking is cancelled, but the Google event could not be removed because sync is not operational.";
    } else {
      await recordGoogleSync(supabase, bookingId, google, true);
      syncNote =
        google.status === "synced"
          ? " The Google Calendar event was removed."
          : " The internal booking is cancelled, but Google Calendar deletion failed.";
    }
  }
  await writeAudit(supabase, {
    actorId: user.id,
    action: "booking_cancelled",
    entityType: "bookings",
    entityId: bookingId,
    detail: {
      previous_status: booking.status,
      slot_id: booking.slot_id,
      reason: cleanReason,
      google_event_id: booking.google_event_id,
    },
  });
  revalidateCalendar();
  return {
    ok: true,
    bookingId,
    message: Booking cancelled. The slot is free.${syncNote},
  };
}
export async function rescheduleBooking(
  bookingId: string,
  newSlotId: string,
  reason: string

  const user = await getSessionUser(supabase);
  if (!user) return { ok: false, error: "Not signed in." };
  if (!isUuid(bookingId) || !isUuid(newSlotId)) {

  const { booking } = loaded;
  if (
    booking.status !== "pending" &&
    booking.status !== "confirmed" &&
    booking.status !== "needs_human"

    return { ok: false, error: "Only an active booking can be rescheduled." };
  }
  if (booking.slot_id === newSlotId) {
    return { ok: false, error: "Choose a different slot." };
  }
  const suppression = await checkSuppressed(supabase, booking.prospect_email);

      ok: false,

        bookingEventInput(booking, loadedSlot.slot, loadedSlot.slot.timezone)

    await supabase
      .from("bookings")

    await recordGoogleSync(supabase, bookingId, google);

      ? " Google Calendar was updated."
      : google.status === "failed"
        ? " Google Calendar sync failed; the internal booking is authoritative."
        : booking.google_event_id
          ? " The Google event was not updated because sync is not operational."
          : "";
  await writeAudit(supabase, {
    actorId: user.id,
    action: "booking_rescheduled",
    entityType: "bookings",
    entityId: bookingId,
    detail: {
      old_slot_id: booking.slot_id,
      new_slot_id: newSlotId,
      previous_status: booking.status,
      reason: cleanReason,
      google_sync: google.status,
    },
  });
  revalidateCalendar();
  return {
    ok: true,
    bookingId,
    slotId: newSlotId,
    message: Booking rescheduled. The old slot is free and the new slot is held.${syncNote},
  };
}

recordGoogleSync() ignores database update errors. That can leave the UI believing synchronization metadata was saved when it wasn't.
bookSlot() updates the conversation separately from creating its booking. A failed conversation update can leave inconsistent state.

2. How I propose fixing it
We'll create a new migration, tentatively:
20261114_04_transactional_calendar_operations.sql
The database will own the critical booking operations.

  **Proposed transaction flow**

  
    **Authenticated application action**

<text color="secondary" size="xs">Validates input and obtains the signed-in user</text>

  
  
    
  
  
    **PostgreSQL transaction**

- Acquire a transaction-level calendar lock
- Lock affected booking and slot rows
- Check availability and suppression
- Change booking/conversation state
- Insert audit record

  
  
    
  
  
    **Transaction commits**

<span class="ce-badge ce-badge-success">All internal changes succeed together</span>

  
  
    
  
  
    **Google Calendar synchronization**

<text color="secondary" size="xs">Separate external operation, with failure recorded without undoing the internal booking</text>

  


The calendar lock is important: locking only the selected slot would not protect us from two different slots whose time ranges overlap. All calendar mutations must participate in the same locking protocol.
Database functions
We'll implement these six operations:

create_calendar_slot
delete_calendar_slot
book_slot
confirm_booking
cancel_booking
reschedule_booking

Each function will authenticate its caller, enforce valid state transitions, and write its audit record in the same transaction.
For rescheduling, we'll lock the booking and affected slots in a consistent order. The previous slot will become available when the booking moves.
3. One important Google Calendar detail
We must not revoke every possible booking update without considering recordGoogleSync().
The internal booking state and the external Google synchronization metadata are different responsibilities.
We'll preserve a narrowly scoped way to update:

google_event_id
calendar_sync_status
calendar_synced_at

The application must not regain permission to directly change booking status, slot assignment, or other protected booking fields.
Google synchronization will remain optional. A Google API failure must never roll back a successful internal booking.

Step 1 — Create migration 04
This migration will introduce:

Transactional RPCs for creating/deleting slots and booking, confirming, cancelling, and rescheduling.
A shared advisory lock for calendar mutations.
Row locking and server-side validation inside each transaction.
Audit records written in the same transaction as each state change.
Restricted direct table permissions: calendar slots and bookings become read-only to authenticated clients; mutations go through RPCs.
A narrowly scoped RPC for recording Google Calendar sync metadata.

One historical-data safeguard: deleting a slot will be rejected if any booking references it, not just an active booking. That preserves the relationship between past bookings and their original slot.

-- Ledgerwise migration 04
-- Transactional calendar operations and restricted table mutations.
--
-- Apply only after reviewing this migration alongside migrations 01-03.
-- All calendar mutations use one transaction-scoped advisory lock.
-- Google Calendar API calls remain outside these database transactions.

-- ---------------------------------------------------------------------------
-- 1. Create calendar slot
-- ---------------------------------------------------------------------------

create or replace function public.create_calendar_slot(
  p_start_time timestamptz,
  p_end_time timestamptz,
  p_timezone text
)
returns uuid
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
  v_slot_id uuid;
  v_local_start timestamp;
  v_local_end timestamp;
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  perform pg_advisory_xact_lock(734921, 1);

  if p_start_time is null or p_end_time is null
     or p_end_time <= p_start_time then
    raise exception 'Invalid slot time range';
  end if;

  if p_start_time <= now() then
    raise exception 'A calendar slot must be in the future';
  end if;

  if p_timezone is null or not exists (
    select 1 from pg_timezone_names where name = p_timezone
  ) then
    raise exception 'Invalid timezone';
  end if;

  if extract(epoch from (p_end_time - p_start_time)) / 60 not between 15 and 120 then
    raise exception 'Slot duration must be between 15 and 120 minutes';
  end if;

  v_local_start := p_start_time at time zone p_timezone;
  v_local_end := p_end_time at time zone p_timezone;

  if v_local_start::date <> v_local_end::date
     or v_local_start::time < time '09:00'
     or v_local_end::time > time '17:00' then
    raise exception 'Slots must remain within 09:00-17:00 local business hours';
  end if;

  if exists (
    select 1
    from public.calendar_slots s
    where s.is_available = true
      and s.start_time < p_end_time
      and s.end_time > p_start_time
  ) then
    raise exception 'This slot overlaps an existing available slot';
  end if;

  insert into public.calendar_slots (
    start_time,
    end_time,
    timezone,
    source,
    external_id,
    is_available,
    fetched_at
  )
  values (
    p_start_time,
    p_end_time,
    p_timezone,
    'internal',
    null,
    true,
    now()
  )
  returning id into v_slot_id;

  insert into public.audit_logs (
    actor_id, action, entity_type, entity_id, detail
  )
  values (
    v_actor,
    'calendar_slot_created',
    'calendar_slot',
    v_slot_id,
    jsonb_build_object(
      'start_time', p_start_time,
      'end_time', p_end_time,
      'timezone', p_timezone
    )
  );

  return v_slot_id;
end;
$$;

create or replace function public.delete_calendar_slot(
  p_slot_id uuid
)
returns boolean
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
  v_slot public.calendar_slots%rowtype;
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  if p_slot_id is null then
    raise exception 'Slot ID is required';
  end if;

  perform pg_advisory_xact_lock(734921, 1);

  select *
  into v_slot
  from public.calendar_slots
  where id = p_slot_id
  for update;

  if not found then
    raise exception 'Calendar slot not found';
  end if;

  if exists (
    select 1
    from public.bookings b
    where b.slot_id = p_slot_id
      and b.status in ('pending', 'confirmed', 'needs_human')
  ) then
    raise exception 'Cannot delete a slot with an active booking';
  end if;

  if exists (
    select 1
    from public.bookings b
    where b.slot_id = p_slot_id
  ) then
    raise exception 'Cannot delete a slot referenced by booking history';
  end if;

  delete from public.calendar_slots
  where id = p_slot_id;

  insert into public.audit_logs (
    actor_id, action, entity_type, entity_id, detail
  )
  values (
    v_actor,
    'calendar_slot_deleted',
    'calendar_slot',
    p_slot_id,
    jsonb_build_object(
      'start_time', v_slot.start_time,
      'end_time', v_slot.end_time,
      'timezone', v_slot.timezone
    )
  );

  return true;
end;
$$;

-- 3. Book slot

create or replace function public.book_slot(
  p_slot_id uuid,
  p_company_id uuid,
  p_conversation_id uuid,
  p_prospect_name text,
  p_prospect_email text,
  p_timezone text
)
returns uuid
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
  v_slot public.calendar_slots%rowtype;
  v_booking_id uuid;
  v_company_id uuid := p_company_id;
  v_email text := lower(btrim(coalesce(p_prospect_email, '')));
  v_conversation_company_id uuid;
  v_conversation_email text;
  v_conversation_status text;
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  perform pg_advisory_xact_lock(734921, 1);

  if p_slot_id is null then
    raise exception 'Slot ID is required';
  end if;

  if nullif(btrim(coalesce(p_prospect_name, '')), '') is null then
    raise exception 'Prospect name is required';
  end if;

  if v_email !~* '^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$' then
    raise exception 'A valid prospect email is required';
  end if;

  if p_timezone is null or not exists (
    select 1 from pg_timezone_names where name = p_timezone
  ) then
    raise exception 'Invalid timezone';
  end if;

  if exists (
    select 1
    from public.suppressed_contacts s
    where lower(s.email) = v_email
  ) then
    raise exception 'This contact is suppressed';
  end if;

  if p_conversation_id is not null then
    select c.company_id, lower(c.contact_email), c.status
    into v_conversation_company_id, v_conversation_email, v_conversation_status
    from public.conversations c
    where c.id = p_conversation_id
    for update;

    if not found then
      raise exception 'Conversation not found';
    end if;

    if v_conversation_status = 'suppressed' then
      raise exception 'This conversation is suppressed';
    end if;

    if v_conversation_email <> v_email then
      raise exception 'Prospect email does not match the conversation';
    end if;

    if v_company_id is null then
      v_company_id := v_conversation_company_id;
    elsif v_company_id <> v_conversation_company_id then
      raise exception 'Company does not match the conversation';
    end if;
  end if;

  select *
  into v_slot
  from public.calendar_slots
  where id = p_slot_id
  for update;

  if not found then
    raise exception 'Calendar slot not found';
  end if;

  if not v_slot.is_available then
    raise exception 'This slot is not available';
  end if;

  if v_slot.start_time <= now() then
    raise exception 'This slot is in the past';
  end if;

  if exists (
    select 1
    from public.bookings b
    join public.calendar_slots s on s.id = b.slot_id
    where b.status in ('pending', 'confirmed', 'needs_human')
      and s.start_time < v_slot.end_time
      and s.end_time > v_slot.start_time
  ) then
    raise exception 'This time overlaps an existing booking';
  end if;

  insert into public.bookings (
    company_id,
    conversation_id,
    slot_id,
    prospect_name,
    prospect_email,
    timezone,
    status
  )
  values (
    v_company_id,
    p_conversation_id,
    p_slot_id,
    btrim(p_prospect_name),
    v_email,
    p_timezone,
    'pending'
  )
  returning id into v_booking_id;

  if p_conversation_id is not null then
    update public.conversations
    set status = 'human_takeover',
        booking_request = false
    where id = p_conversation_id;
  end if;

  insert into public.audit_logs (
    actor_id, action, entity_type, entity_id, detail
  )
  values (
    v_actor,
    'booking_created',
    'booking',
    v_booking_id,
    jsonb_build_object(
      'slot_id', p_slot_id,
      'company_id', v_company_id,
      'conversation_id', p_conversation_id,
      'prospect_email', v_email,
      'status', 'pending'
    )
  );

  return v_booking_id;
end;
$$;

-- 4. Confirm booking
-- ---------------------------------------------------------------------------

create or replace function public.confirm_booking(
  p_booking_id uuid
)
returns boolean
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
  v_booking public.bookings%rowtype;
  v_slot public.calendar_slots%rowtype;
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  if p_booking_id is null then
    raise exception 'Booking ID is required';
  end if;

  perform pg_advisory_xact_lock(734921, 1);

  select *
  into v_booking
  from public.bookings
  where id = p_booking_id
  for update;

  if not found then
    raise exception 'Booking not found';
  end if;

  if v_booking.status not in ('pending', 'needs_human') then
    raise exception 'This booking cannot be confirmed from its current status';
  end if;

  if exists (
    select 1
    from public.suppressed_contacts s
    where lower(s.email) = lower(v_booking.prospect_email)
  ) then
    raise exception 'This contact is suppressed';
  end if;

  if v_booking.slot_id is null then
    raise exception 'Booking has no calendar slot';
  end if;

  select *
  into v_slot
  from public.calendar_slots
  where id = v_booking.slot_id
  for update;

  if not found or not v_slot.is_available or v_slot.start_time <= now() then
    raise exception 'The booked slot is no longer available';
  end if;

  if exists (
    select 1
    from public.bookings b
    join public.calendar_slots s on s.id = b.slot_id
    where b.id <> p_booking_id
      and b.status in ('pending', 'confirmed', 'needs_human')
      and s.start_time < v_slot.end_time
      and s.end_time > v_slot.start_time
  ) then
    raise exception 'Another active booking overlaps this slot';
  end if;

  update public.bookings
  set status = 'confirmed'
  where id = p_booking_id;

  insert into public.audit_logs (
    actor_id, action, entity_type, entity_id, detail
  )
  values (
    v_actor,
    'booking_confirmed',
    'booking',
    p_booking_id,
    jsonb_build_object('previous_status', v_booking.status)
  );

  return true;
end;
$$;

-- ---------------------------------------------------------------------------
-- 6. Reschedule booking
-- ---------------------------------------------------------------------------

create or replace function public.reschedule_booking(
  p_booking_id uuid,
  p_new_slot_id uuid,
  p_reason text
)
returns boolean
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
  v_booking public.bookings%rowtype;
  v_new_slot public.calendar_slots%rowtype;
  v_reason text := nullif(btrim(coalesce(p_reason, '')), '');
  v_old_slot_id uuid;
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  if p_booking_id is null or p_new_slot_id is null then
    raise exception 'Booking ID and new slot ID are required';
  end if;

  if v_reason is null then
    raise exception 'A rescheduling reason is required';
  end if;

  perform pg_advisory_xact_lock(734921, 1);

  select *
  into v_booking
  from public.bookings
  where id = p_booking_id
  for update;

  if not found then
    raise exception 'Booking not found';
  end if;

  if v_booking.status not in ('pending', 'confirmed', 'needs_human') then
    raise exception 'This booking cannot be rescheduled from its current status';
  end if;

  if v_booking.slot_id = p_new_slot_id then
    raise exception 'Choose a different slot';
  end if;

  if exists (
    select 1
    from public.suppressed_contacts s
    where lower(s.email) = lower(v_booking.prospect_email)
  ) then
    raise exception 'This contact is suppressed';
  end if;

  v_old_slot_id := v_booking.slot_id;

  -- Lock both slot rows in stable ID order.
  perform s.id
  from public.calendar_slots s
  where s.id in (v_old_slot_id, p_new_slot_id)
  order by s.id
  for update;

  select *
  into v_new_slot
  from public.calendar_slots
  where id = p_new_slot_id;

  if not found then
    raise exception 'New calendar slot not found';
  end if;

  if not v_new_slot.is_available or v_new_slot.start_time <= now() then
    raise exception 'New slot is not available';
  end if;

  if exists (
    select 1
    from public.bookings b
    join public.calendar_slots s on s.id = b.slot_id
    where b.id <> p_booking_id
      and b.status in ('pending', 'confirmed', 'needs_human')
      and s.start_time < v_new_slot.end_time
      and s.end_time > v_new_slot.start_time
  ) then
    raise exception 'New slot overlaps an existing booking';
  end if;

  update public.bookings
  set slot_id = p_new_slot_id,
      status = 'pending'
  where id = p_booking_id;

  insert into public.audit_logs (
    actor_id, action, entity_type, entity_id, detail
  )
  values (
    v_actor,
    'booking_rescheduled',
    'booking',
    p_booking_id,
    jsonb_build_object(
      'old_slot_id', v_old_slot_id,
      'new_slot_id', p_new_slot_id,
      'previous_status', v_booking.status,
      'reason', v_reason
    )
  );

  return true;
end;
$$;


-- ---------------------------------------------------------------------------
-- 7. Record Google Calendar sync metadata
-- ---------------------------------------------------------------------------
-- This RPC only updates sync metadata. It does not perform Google API calls.
-- OAuth, token security, retries, and reconciliation are separate work.

create or replace function public.record_google_calendar_sync(
  p_booking_id uuid,
  p_status text,
  p_event_id text default null
)
returns boolean
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  if p_booking_id is null then
    raise exception 'Booking ID is required';
  end if;

  if p_status not in ('pending', 'synced', 'failed', 'deleted', 'not_configured') then
    raise exception 'Invalid Google Calendar sync status';
  end if;

  if p_status = 'synced' and nullif(btrim(coalesce(p_event_id, '')), '') is null then
    raise exception 'A Google event ID is required for synced status';
  end if;

  update public.bookings
  set google_event_id = case
        when p_status = 'deleted' then null
        when p_event_id is not null then p_event_id
        else google_event_id
      end,
      calendar_sync_status = p_status,
      calendar_synced_at = now()
  where id = p_booking_id;

  if not found then
    raise exception 'Booking not found';
  end if;

  return true;
end;
$$;

create or replace function public.confirm_booking(
  p_booking_id uuid
)
returns boolean
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
  v_booking public.bookings%rowtype;
  v_slot public.calendar_slots%rowtype;
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  if p_booking_id is null then
    raise exception 'Booking ID is required';
  end if;

  perform pg_advisory_xact_lock(734921, 1);

  select *
  into v_booking
  from public.bookings
  where id = p_booking_id
  for update;

  if not found then
    raise exception 'Booking not found';
  end if;

  if v_booking.status not in ('pending', 'needs_human') then
    raise exception 'This booking cannot be confirmed from its current status';
  end if;

  if exists (
    select 1
    from public.suppressed_contacts s
    where lower(s.email) = lower(v_booking.prospect_email)
  ) then
    raise exception 'This contact is suppressed';
  end if;

  if v_booking.slot_id is null then
    raise exception 'Booking has no calendar slot';
  end if;

  select *
  into v_slot
  from public.calendar_slots
  where id = v_booking.slot_id
  for update;

  if not found or not v_slot.is_available or v_slot.start_time <= now() then
    raise exception 'The booked slot is no longer available';
  end if;

  if exists (
    select 1
    from public.bookings b
    join public.calendar_slots s on s.id = b.slot_id
    where b.id <> p_booking_id
      and b.status in ('pending', 'confirmed', 'needs_human')
      and s.start_time < v_slot.end_time
      and s.end_time > v_slot.start_time
  ) then
    raise exception 'Another active booking overlaps this slot';
  end if;

  update public.bookings
  set status = 'confirmed'
  where id = p_booking_id;

  insert into public.audit_logs (
    actor_id, action, entity_type, entity_id, detail
  )
  values (
    v_actor,
    'booking_confirmed',
    'booking',
    p_booking_id,
    jsonb_build_object('previous_status', v_booking.status)
  );

  return true;
end;
$$;

create or replace function public.reschedule_booking(
  p_booking_id uuid,
  p_new_slot_id uuid,
  p_reason text
)
returns boolean
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
  v_booking public.bookings%rowtype;
  v_new_slot public.calendar_slots%rowtype;
  v_reason text := nullif(btrim(coalesce(p_reason, '')), '');
  v_old_slot_id uuid;
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  if p_booking_id is null or p_new_slot_id is null then
    raise exception 'Booking ID and new slot ID are required';
  end if;

  if v_reason is null then
    raise exception 'A rescheduling reason is required';
  end if;

  perform pg_advisory_xact_lock(734921, 1);

  select *
  into v_booking
  from public.bookings
  where id = p_booking_id
  for update;

  if not found then
    raise exception 'Booking not found';
  end if;

  if v_booking.status not in ('pending', 'confirmed', 'needs_human') then
    raise exception 'This booking cannot be rescheduled from its current status';
  end if;

  if v_booking.slot_id = p_new_slot_id then
    raise exception 'Choose a different slot';
  end if;

  if exists (
    select 1
    from public.suppressed_contacts s
    where lower(s.email) = lower(v_booking.prospect_email)
  ) then
    raise exception 'This contact is suppressed';
  end if;

  v_old_slot_id := v_booking.slot_id;

  -- Lock both slot rows in stable ID order.
  perform s.id
  from public.calendar_slots s
  where s.id in (v_old_slot_id, p_new_slot_id)
  order by s.id
  for update;

  select *
  into v_new_slot
  from public.calendar_slots
  where id = p_new_slot_id;

  if not found then
    raise exception 'New calendar slot not found';
  end if;

  if not v_new_slot.is_available or v_new_slot.start_time <= now() then
    raise exception 'New slot is not available';
  end if;

  if exists (
    select 1
    from public.bookings b
    join public.calendar_slots s on s.id = b.slot_id
    where b.id <> p_booking_id
      and b.status in ('pending', 'confirmed', 'needs_human')
      and s.start_time < v_new_slot.end_time
      and s.end_time > v_new_slot.start_time
  ) then
    raise exception 'New slot overlaps an existing booking';
  end if;

  update public.bookings
  set slot_id = p_new_slot_id,
      status = 'pending'
  where id = p_booking_id;

  insert into public.audit_logs (
    actor_id, action, entity_type, entity_id, detail
  )
  values (
    v_actor,
    'booking_rescheduled',
    'booking',
    p_booking_id,
    jsonb_build_object(
      'old_slot_id', v_old_slot_id,
      'new_slot_id', p_new_slot_id,
      'previous_status', v_booking.status,
      'reason', v_reason
    )
  );

  return true;
end;
$$;

create or replace function public.record_google_calendar_sync(
  p_booking_id uuid,
  p_status text,
  p_event_id text default null
)
returns boolean
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_actor uuid := auth.uid();
begin
  if v_actor is null then
    raise exception 'Authentication required';
  end if;

  if p_booking_id is null then
    raise exception 'Booking ID is required';
  end if;

import type { ServerSupabase } from "./server/auth";
import { isValidEmail, normalizeEmail } from "./validation";
export type SuppressionRow = {
  id: string;
  email: string;
  reason: string;
  source_message_id: string | null;
  created_at: string;
};
export type SuppressResult =
  | { ok: true; row: SuppressionRow }
  | { ok: false; error: string };
export function suppressionErrorMessage(code: string): string {
  switch (code) {
    case "not_authenticated":
      return "You must be signed in to update the suppression list.";
    case "invalid_email":
      return "The contact email is not valid.";
    default:
      return "The contact could not be added to the suppression list.";
  }
}
export async function isSuppressed(
  supabase: ServerSupabase,
  email: string
): Promise {
  const normalized = normalizeEmail(email);
  if (!normalized) return false;
  const { data, error } = await supabase.rpc("is_suppressed", {
    p_email: normalized,
  });
  if (error) throw new Error(Suppression check failed: ${error.message});
  return Boolean(data);
}
export async function suppressContact(
  supabase: ServerSupabase,
  input: {
    email: string;
    reason: string;
    sourceMessageId?: string | null;
  }
): Promise {
  const email = normalizeEmail(input.email);
  if (!isValidEmail(email)) {
    return { ok: false, error: suppressionErrorMessage("invalid_email") };
  }
  const { data, error } = await supabase.rpc("suppress_contact", {
    p_email: email,
    p_reason: input.reason,
    p_source_message_id: input.sourceMessageId ?? null,
  });
  if (error) {
    return { ok: false, error: suppressionErrorMessage(error.message) };
  }
  const row = (Array.isArray(data) ? data[0] : data) as SuppressionRow | null;
  if (!row) return { ok: false, error: "The contact could not be suppressed." };
  return { ok: true, row };
}

This confirms the suppression race, and it reveals one additional security issue we should fix before proceeding.
1. Suppression can currently bypass its own RPC
Your suppressContact() application helper correctly uses the suppress_contact RPC. However, migration 01 also gives authenticated users direct INSERT access to suppressed_contacts (according to the migration review so far).
That means a client could insert a suppression record without:

Acquiring the calendar advisory lock.
Writing the expected audit record through the RPC.
Participating in the same concurrency protocol as booking.

Correction: migration 04 should revoke direct INSERT on suppressed_contacts from authenticated, while retaining the intended read access. The suppress_contact security-definer function should acquire the same advisory transaction lock used by calendar operations.
Then suppression and booking will serialize against each other. A booking cannot slip through while a concurrent suppression is being committed.
2. Calendar reads are fine; writes need refactoring
Your grep results show that the calendar page reads slots and bookings, which is compatible with the proposed read-only grants.
The calls in calendar/actions.ts need more careful classification:

Reads such as loadSlot and loadBooking can remain direct queries.
Slot creation and deletion must use their RPCs.
Booking creation, confirmation, cancellation, and rescheduling must use their RPCs.
Google sync metadata updates must use the restricted metadata RPC, not direct .update() calls.

The application should check every RPC's returned error and handle failures without pretending the operation succeeded.
